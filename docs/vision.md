# Vision

Loomspace is not a single linear chat. It is a woven workspace.

## UX principles

- primary stream stays visually dominant
- side streams stay easy to spawn and inspect
- useful pairs can be stitched into the main line
- saturation should be visible, not hidden
- memory is a fabric, not a trash heap

## Open questions

- how much should the user control promotion?
- should stitches be reversible?
- how do we visualize density without clutter?
